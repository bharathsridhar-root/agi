## 🎯 Quick Start (5 Steps)

### Step 1: Verify You Have Access
✅ You have push access to: `https://github.com/bharathsridhar-root/agi`

### Step 2: Copy Website Files
```bash
# Navigate to your AGI repo
cd ~/path/to/agi

# Copy all website files (choose one):
# On Mac/Linux:
cp -r /home/claude/constitutional-ai-website/* .

# On Windows (PowerShell):
Copy-Item -Path "C:\path\to\constitutional-ai-website\*" -Destination "." -Recurse
```

### Step 3: Push to GitHub
```bash
git add .
git commit -m "Add Constitutional AI Platform website"
git push origin main
```

### Step 4: Deploy to AWS Amplify
1. Go to: https://console.aws.amazon.com/amplify
2. Click **"New app"** → **"Host web app"**
3. Select **GitHub** → Authorize
4. Select repository: `bharathsridhar-root/agi`
5. Select branch: `main`
6. Click **"Save and deploy"**

### Step 5: Wait (~5 minutes) & Share
Your site will be live at: `https://main.[random-id].amplifyapp.com`
